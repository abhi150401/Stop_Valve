# Stop Valve Mechanical Design Project

## Overview
This repository contains the complete 3D modeling, assembly, and 2D engineering drafting for an industrial Stop Valve. 

## Software Used
* **SolidWorks / AutoCAD** (Keep the one you used)

## Features Included
* **3D Parts & Assembly:** Complete modeling of the Valve Body, Stem, Bonnet, and Handwheel with proper mechanical constraints.
* **2D Draftings:** Fully dimensioned production drawings, sectional views showing fluid flow, and Bill of Materials (BOM).
